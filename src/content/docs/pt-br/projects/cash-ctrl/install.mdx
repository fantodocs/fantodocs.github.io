## Requisitos

Antes de instalar o cash-ctrl, certifique-se de que seu computador possui os seguintes programas instalados:

- **.NET 10 Runtime** ou SDK - necessário para executar aplicativos .NET
- **Windows 11** - o aplicativo foi desenvolvido especificamente para Windows

## Instalação rápida

Escolha seu sistema operacional abaixo para instalar o cash-ctrl com um único comando:

<Tabs>
  <TabItem label="Windows">

```powershell
# Baixe e execute o instalador
Invoke-WebRequest -Uri "https://github.com/F4NT0/cash-ctrl/releases/latest/download/cash-ctrl-installer.exe" -OutFile "$env:TEMP\cash-ctrl-installer.exe"; Start-Process -FilePath "$env:TEMP\cash-ctrl-installer.exe" -Verb RunAs
```

## Instalação manual

### Windows

<Steps>
1. Baixe o instalador mais recente da [página de releases](https://github.com/F4NT0/cash-ctrl/releases)

   <div class="step-image-slot"><img src="/projects/cash-ctrl/install-win-1.png" alt="Baixando o instalador" loading="lazy" onerror="this.parentElement.classList.add('empty')" /></div>

2. Execute o arquivo `cash-ctrl-installer.exe` e valide a localização que vai ser instalado.

   <div class="step-image-slot"><img src="/projects/cash-ctrl/install-win-2.png" alt="Executando o instalador" loading="lazy" onerror="this.parentElement.classList.add('empty')" /></div>

3. O instalador vai mostrar todos os passos que ele vai fazer no seu computador.

   <div class="step-image-slot"><img src="/projects/cash-ctrl/install-win-3.png" alt="Instruções do instalador" loading="lazy" onerror="this.parentElement.classList.add('empty')" /></div>

4. O instalador também verifica se você já tem instalado no seu computador e pergunta se deseja reinstalar.

   <div class="step-image-slot"><img src="/projects/cash-ctrl/install-win-4.png" alt="cash-ctrl override" loading="lazy" onerror="this.parentElement.classList.add('empty')" /></div>

5. Após confirmação, ele vai mostrar a instalação e passos até concluir.

   <div class="step-image-slot"><img src="/projects/cash-ctrl/install-win-5.png" alt="cash-ctrl override" loading="lazy" onerror="this.parentElement.classList.add('empty')" /></div>

6. Para confirmar, abra um novo terminal e use o comando `cash-ctrl --version`.

   <div class="step-image-slot"><img src="/projects/cash-ctrl/install-win-6.png" alt="cash-ctrl override" loading="lazy" onerror="this.parentElement.classList.add('empty')" /></div>



</Steps>
