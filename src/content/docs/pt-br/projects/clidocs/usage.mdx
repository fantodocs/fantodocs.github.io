## Executando o programa

```powershell
# Abre a pasta padrão de snippets (~\clidocs_snippets)
clidocs

# Abre a pasta atual como raiz dos snippets
clidocs .

# Abre uma pasta específica
clidocs C:\Users\You\my-snippets
clidocs .\docs\snippets
```

:::note[Snippets]
Os snippets ficam salvos em `%USERPROFILE%\clidocs_snippets\`. A pasta é criada na primeira execução e cada subpasta vira uma categoria no painel Folders.
:::

## Comandos

| Comando | Descrição |
|---|---|
| `clidocs` | Inicia com a tela inicial (pasta padrão de snippets ou escolher outra) |
| `clidocs .` | Abre a pasta atual como raiz dos snippets |
| `clidocs <caminho>` | Abre uma pasta específica, pulando a tela inicial |
| `clidocs --help` | Ajuda interativa com uma aba por tópico (`-h`, `help`) |
| `clidocs --version` | Mostra a versão instalada (`-v`, `version`) |
| `clidocs --install` | Instala ou atualiza pela última release do GitHub |
| `clidocs --uninstall` | Remove o clidocs do computador |

## Interface

### Tela inicial

Esta é a tela inicial do programa, exibida quando você executa o comando `clidocs` sem argumentos. Use `↑` / `↓` para escolher entre abrir a pasta padrão de snippets ou procurar outra pasta, `Enter` para confirmar e `Ctrl+C` para sair.

![Tela inicial do clidocs](/projects/clidocs/interface.png)

### Tela principal

Esta é a tela principal do programa, exibida depois que você escolhe uma pasta. Ela fica vazia no primeiro uso: pressione `n` no painel Folders para criar sua primeira pasta. A barra inferior lista os atalhos do painel ativo.

A tela é dividida em três painéis. `Tab` alterna entre eles e o painel ativo tem a borda azul.

| Painel | O que faz |
|---|---|
| **Folders** | Lista as pastas e subpastas do diretório de snippets. Pastas com subpastas mostram o marcador `>` e os favoritos mostram uma estrela. |
| **Files** | Lista os arquivos da pasta selecionada com a tag da linguagem e a idade de cada arquivo. |
| **Preview** | Mostra o arquivo selecionado com destaque de sintaxe, ou Markdown renderizado (tabelas, listas, cores de TODO e ícones). |

![Tela principal com os três painéis](/projects/clidocs/main-screen.png)

## Painéis e atalhos

### Atalhos globais

| Tecla | Ação |
|---|---|
| `Tab` | Próximo painel |
| `s` | Vai para o painel Folders |
| `g` | Sincroniza os snippets com o Git |
| `G` | Edita a configuração do Git |
| `:` | Abre o console de comandos |
| `q` / `Ctrl+C` | Sair |

### Painel Folders

Mostra as pastas do diretório de snippets. Mover o cursor atualiza os painéis Files e Preview. `Enter` em uma pasta com subpastas entra no **parent-view**: a primeira linha é `~/` (os arquivos da própria pasta), seguida de uma linha por subpasta. `←` volta um nível.

![Painel Folders](/projects/clidocs/folders-panel.png)

| Tecla | Ação |
|---|---|
| `↑` / `k`, `↓` / `j` | Move o cursor |
| `Enter` / `→` / `l` | Abre a pasta (entra no parent-view se tiver subpastas) |
| `←` / `h` | Volta um nível |
| `n` | Nova pasta |
| `N` | Nova subpasta dentro da pasta selecionada |
| `r` | Renomeia a pasta selecionada |
| `d` | Apaga a pasta selecionada (exige confirmação) |
| `D` | Modo de exclusão múltipla: `Space` seleciona, `D` confirma, `Esc` cancela |
| `/` | Busca pastas recursivamente |
| `f` | Favorita / desfavorita a pasta selecionada |
| `F` | Abre a lista de favoritos |
| `H` | Volta ao diretório original de snippets |
| `o` | Mostra informações sobre o diretório de snippets |

### Painel Files

Mostra os arquivos da pasta selecionada. O título mostra quantos snippets existem. Cada linha tem a tag da linguagem, o nome do arquivo e a pasta com a idade do arquivo.

![Painel Files](/projects/clidocs/files-panel.png)

| Tecla | Ação |
|---|---|
| `↑` / `k`, `↓` / `j` | Move o cursor (o Preview atualiza ao vivo) |
| `Enter` / `e` | Abre o arquivo no Neovim |
| `n` | Novo arquivo |
| `r` | Renomeia o arquivo selecionado |
| `d` | Apaga o arquivo selecionado (exige confirmação) |
| `m` | Move o arquivo para outra pasta |
| `c` | Importa um arquivo de qualquer lugar com o seletor de arquivos |
| `/` | Filtra arquivos pelo nome (aceita globs como `*.go`) |

### Painel Preview (snippet)

Mostra o conteúdo do arquivo selecionado. O código é destacado com o tema GitHub Dark e o Markdown é renderizado com títulos, listas e tabelas estilizados.

![Painel Preview](/projects/clidocs/preview-panel.png)

| Tecla | Ação |
|---|---|
| `↑` / `k`, `↓` / `j` | Rola |
| `c` | Copia o arquivo inteiro para a área de transferência |
| `e` | Edita o arquivo no Neovim |
| `o` | Abre a localização do arquivo no Windows Explorer |
| `z` | Alterna o zoom (o preview ocupa a tela toda) |
| `L` | Alterna os números de linha |
| `/` | Busca uma palavra no arquivo; `Enter` encontra os resultados e `n` / `N` pulam entre eles |

## Como usar

### Criar pastas e subpastas

<Steps>
1. Foque o painel **Folders**.
2. Pressione `n`, digite o nome e pressione `Enter` para criar uma pasta.
3. Selecione uma pasta e pressione `N` para criar uma **subpasta** dentro dela.
4. `Esc` cancela.
</Steps>

![Criar pasta](/projects/clidocs/create-folder.png)

Para criar uma subpasta, selecione a pasta pai e pressione `N`. O diálogo mostra em qual pasta a nova subpasta será criada (`Inside: Folder1/`). Pastas que contêm subpastas mostram o marcador `>` na lista.

![Criar subpasta](/projects/clidocs/create-subfolder.png)

### Renomear uma pasta

:::note
A opção de renomear só está disponível quando o painel **Folders** está em foco (use `s` ou `Tab` para chegar até ele).
:::

<Steps>
1. Selecione a pasta no painel Folders.
2. Pressione `r`. Um diálogo mostra o nome atual (`Current: Folder1/`) e um campo já preenchido para o novo nome.
3. Digite o novo nome e pressione `Enter` para confirmar, ou `Esc` para cancelar.
</Steps>

![Renomear pasta](/projects/clidocs/rename-folder.png)

### Favoritar uma pasta

:::note
Os favoritos só estão disponíveis quando o painel **Folders** está em foco.
:::

<Steps>
1. Selecione a pasta no painel Folders.
2. Pressione `f`. Uma estrela aparece ao lado do nome da pasta.
3. Pressione `f` de novo na mesma pasta para remover a estrela.
4. Pressione `F` (maiúsculo) para abrir a lista de favoritos.
</Steps>

![Favoritar pasta](/projects/clidocs/favorite-folder.png)

Na lista de favoritos use `↑` / `↓` para navegar, `Enter` para ir até a pasta, `o` para abri-la no Explorer, `f` para removê-la dos favoritos e `Esc` para fechar.

![Lista de favoritos](/projects/clidocs/favorites-list.png)

### Apagar pastas

:::danger
Apagar pastas só está disponível quando o painel **Folders** está em foco. Apagar uma pasta remove tudo que está dentro dela.
:::

<Tabs>
  <TabItem label="Uma pasta">

Selecione a pasta e pressione `d`. Um diálogo pede confirmação e avisa que a pasta e todo o seu conteúdo serão apagados e que isso não pode ser desfeito. Pressione `Enter` ou `y` para apagar, ou `Esc` ou `n` para cancelar.

![Apagar pasta](/projects/clidocs/delete-folder.png)

  </TabItem>
  <TabItem label="Várias pastas">

Pressione `D` para entrar no modo de exclusão múltipla, mova com `↑` / `↓`, pressione `Space` para selecionar ou desmarcar cada pasta, pressione `D` de novo para confirmar e `Esc` para cancelar. As pastas selecionadas ficam destacadas em vermelho. Um diálogo mostra quantas pastas serão apagadas e avisa que isso não pode ser desfeito. Pressione `Enter` ou `y` para apagar, ou `Esc` ou `n` para cancelar.

![Apagar várias pastas](/projects/clidocs/delete-multiple-folders.png)

  </TabItem>
</Tabs>

### Criar arquivos dentro de uma pasta

<Steps>
1. Selecione uma pasta e foque o painel **Files** com `Tab`.
2. Pressione `n`.
3. Digite o nome do arquivo (sem extensão) e pressione `Enter` ou `Tab`.
4. Digite a extensão (por exemplo `go`, `py`, `md`) e pressione `Enter`. O arquivo é criado e aberto no Neovim.
</Steps>

![Criar arquivo](/projects/clidocs/create-file.png)

### Editar arquivos

Pressione `Enter` ou `e` em um arquivo (painel Files) ou `e` (painel Preview) para abri-lo no Neovim. Salve com `:w`, saia com `:q`, ou faça os dois com `:wq`. Ao voltar para o clidocs o preview é atualizado. No console, o comando `nvim` mostra uma referência rápida do Neovim.

![Editando um arquivo no Neovim](/projects/clidocs/edit-file.png)

### Painel de snippet após salvar

Depois de salvar e sair do Neovim (`:wq`), o clidocs mostra o resultado na hora. O painel Files lista o snippet com a tag da linguagem, a pasta e a idade, e o painel Preview (o painel de snippet) mostra o conteúdo salvo: o Markdown é renderizado com texto estilizado e links, e os arquivos de código recebem destaque de sintaxe. A partir daqui você pode rolar, buscar (`/`), copiar (`c`), editar de novo (`e`) ou abrir a pasta (`o`).

![Painel de snippet após salvar o arquivo](/projects/clidocs/snippet-panel.png)

### Renomear um arquivo

:::note
A opção de renomear só está disponível quando o painel **Files** está em foco (use `Tab` para chegar até ele).
:::

<Steps>
1. Selecione o arquivo no painel Files.
2. Pressione `r`. Um diálogo mostra o nome atual (`Current: File1.md`) e um campo já preenchido com ele, extensão incluída.
3. Digite o novo nome e pressione `Enter` para confirmar, ou `Esc` para cancelar.
</Steps>

![Renomear arquivo](/projects/clidocs/rename-file.png)

### Mover um arquivo

:::note
Mover arquivos só está disponível quando o painel **Files** está em foco.
:::

<Steps>
1. Selecione o arquivo no painel Files.
2. Pressione `m`. Um diálogo mostra o nome do arquivo e a lista de pastas e subpastas para onde você pode movê-lo.
3. Use `↑` / `↓` para escolher a pasta de destino. A última entrada, `Browse external folder...`, permite escolher uma pasta fora do diretório de snippets.
4. Pressione `Enter` para mover o arquivo, ou `Esc` para cancelar.
</Steps>

![Mover arquivo](/projects/clidocs/move-file.png)

### Importar um arquivo

:::note
Importar arquivos só está disponível quando o painel **Files** está em foco.
:::

<Steps>
1. Selecione a pasta que vai receber os arquivos e foque o painel Files.
2. Pressione `c`. O clidocs abre o seletor de arquivos do Windows (a janela do explorador de arquivos) e mostra a mensagem `Opening file picker...`.
3. No seletor, escolha um ou mais arquivos e confirme. Eles são copiados para a pasta atual (`Folder1` no exemplo).
</Steps>

![Importar arquivo](/projects/clidocs/import-file.png)

### Apagar arquivos

:::caution
Apagar arquivos só está disponível quando o painel **Files** está em foco.
:::

<Steps>
1. Selecione o arquivo no painel Files.
2. Pressione `d`. Um diálogo pergunta `Are you sure you want to delete:` e mostra o nome do arquivo.
3. Pressione `Enter` ou `y` para apagar, ou `Esc` ou `n` para cancelar.
</Steps>

![Apagar arquivo](/projects/clidocs/delete-file.png)

A tecla `/` inicia uma busca em todos os painéis. O que ela busca depende de qual painel está em foco.

### Busca de pastas

Disponível quando o painel **Folders** está em foco.

<Steps>
1. Pressione `/`. Um diálogo de busca abre e lista as pastas, incluindo as subpastas.
2. Digite parte do nome de uma pasta. A lista é filtrada enquanto você digita.
3. Use `↑` / `↓` para escolher um resultado e pressione `Enter` para ir até a pasta.
4. Pressione `Esc` para fechar a busca sem alterar nada.
</Steps>

![Busca de pastas](/projects/clidocs/folder-search.png)

### Busca de arquivos

Disponível quando o painel **Files** está em foco.

<Steps>
1. Pressione `/`. Uma barra de busca substitui o título do painel.
2. Digite parte do nome de um arquivo. A lista é filtrada enquanto você digita e globs como `*.go` são aceitos.
3. Use `↑` / `↓` para percorrer os resultados. O painel Preview atualiza ao vivo.
4. Pressione `Enter` para manter a seleção, ou `Esc` para cancelar e restaurar a lista completa.
</Steps>

![Busca de arquivos](/projects/clidocs/file-search.png)

### Busca no Preview

Disponível quando o painel **Preview** está em foco e há um arquivo carregado. Busca palavras dentro do conteúdo do arquivo.

<Steps>
1. Pressione `/`. Uma barra de busca aparece.
2. Digite a palavra ou frase, inclusive a letra `n`, e pressione `Enter`. Cada ocorrência aparece em **negrito verde** dentro do texto. Em arquivos de código, as linhas com ocorrências também são marcadas: a atual com uma seta laranja e as demais com um ponto verde.
3. Depois do primeiro `Enter`, pressione `n` para ir à próxima ocorrência e `N` para voltar à anterior.
4. Pressione `Esc` para fechar a busca.
</Steps>

![Busca no Preview](/projects/clidocs/preview-search.png)

### Sincronização com o Git

Pressione `g` para sincronizar o diretório de snippets com um repositório Git. Na primeira vez, um diálogo pede o remote; `G` edita a configuração depois. O Git precisa estar instalado.

### Console

Pressione `:` na tela principal para abrir o console (`Cmdline`). Digite um comando e pressione `Enter`. `Esc` fecha o console e, dentro da tela de um comando, `Esc` volta ao console. Comandos desconhecidos mostram `Unknown command` e uma dica para digitar `cmd`.

![Console](/projects/clidocs/console.png)

#### `time`

Calculadora de horas de trabalho. Digite seu horário de entrada como `HH:MM` (por exemplo `08:00`) e pressione `Enter`. Ela mostra o café, o início do almoço, o fim do almoço, a saída normal (8h48 trabalhadas) e a saída máxima (10h trabalhadas). `Enter` volta ao console.

Primeiro, digite o horário de entrada no campo `HH:MM` e pressione `Enter` para calcular (`Esc` volta).

![Entrada do comando time](/projects/clidocs/console-time.png)

Depois o resultado é mostrado. No exemplo, uma entrada às `07:01` dá o café às `08:01`, o almoço das `11:01` às `12:01`, a saída normal às `16:49` (8h48 trabalhadas) e a saída máxima às `18:01` (10h trabalhadas).

![Resultado do comando time](/projects/clidocs/console-time-result.png)

#### `alive`

Mantém o computador acordado. Enquanto esta tela está aberta, o clidocs pressiona a tecla `B` a cada 2 segundos, para que o sistema não bloqueie nem fique inativo. A tecla vai para a janela em foco, então mantenha o clidocs em foco enquanto ele roda. `Esc` interrompe.

#### `whoami`

Mostra informações sobre o autor como se um comando de terminal tivesse sido executado. `Enter` abre o site fantodocs.github.io no navegador e `Esc` volta ao console.

![Comando whoami](/projects/clidocs/console-whoami.png)

#### `cmd`

Mostra a lista de comandos disponíveis no console, cada um com uma descrição curta. Tem duas abas: "Console commands" e "Neovim Quick Reference". Use `←`/`→` ou `Tab` para trocar de aba, `1`/`2` para ir direto a uma delas e `↑`/`↓` para rolar. `Enter` ou `Esc` volta ao console. Os atalhos dos painéis ficam no painel de ajuda, aberto com `?` na tela principal.

![Comando cmd](/projects/clidocs/console-cmd.png)

#### `nvim`

Abre a mesma ajuda do `cmd`, mas direto na aba "Neovim Quick Reference". Mostra navegação, edição, salvar e sair, busca, comentar e descomentar várias linhas e o modo visual. Use `←`/`→` ou `Tab` para trocar para a aba "Console commands". `Enter` ou `Esc` volta ao console.

![Comando nvim](/projects/clidocs/console-nvim.png)

#### `ls` e `cd`

`ls` abre um painel flutuante com a árvore dos diretórios dentro do diretório aberto no clidocs (até 3 níveis, pastas ocultas ignoradas). Use `↑`/`↓` para rolar. No painel, digite `cd <diretório>` (por exemplo `cd Projects` ou `cd Projects/App`) e pressione `Enter`: o painel fecha e os painéis Folders e Files mostram o diretório escolhido. `Esc` volta ao console. No console, `cd <diretório>` também funciona direto, e `cd ..` vai para o diretório pai.

![Comandos ls e cd](/projects/clidocs/console-ls.png)

#### `exit`

Fecha o clidocs por completo (`quit` faz o mesmo).

## Estrutura do projeto

O projeto está em transição para Clean Architecture. Como o Bubble Tea exige os métodos Update/View no mesmo pacote do Model, os arquivos principais ficam na raiz e os auxiliares foram reorganizados:

<FileTree>
- clidocs/
  - cmd/
    - install/ TUI installer
  - core application files (*.go)
  - console_modals.go
  - file_modals.go
  - folder_modals.go
  - git_modals.go
  - other_modals.go
  - README.md
</FileTree>
