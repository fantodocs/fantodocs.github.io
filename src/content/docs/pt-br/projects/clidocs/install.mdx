## Requisitos

| Requisito | Observações |
|---|---|
| **Windows 11 + PowerShell** | Plataforma principal suportada |
| **Neovim (`nvim`)** | Precisa estar no `PATH` para editar arquivos |
| **Git** | Somente para a sincronização com o Git |

## Instalação com um único comando

Escolha o seu sistema operacional:

<Tabs>
  <TabItem label="Windows">

### Opção 1: uma linha (recomendada)

Abra o **PowerShell** e cole o comando abaixo. Ele baixa o `clidocs-installer.exe` da última release do GitHub para uma pasta temporária, executa o instalador (que baixa e instala o `clidocs.exe` da última release) e apaga o instalador temporário.

```powershell title="PowerShell"
$i="$env:TEMP\clidocs-installer.exe"; iwr https://github.com/F4NT0/clidocs/releases/latest/download/clidocs-installer.exe -OutFile $i; & $i; Remove-Item $i -Force
```

:::note
A última release precisa ter o `clidocs-installer.exe` anexado junto ao `clidocs.exe`.
:::

![O instalador mostra os passos que vai ex](/projects/clidocs/one-command-install.png)

O instalador mostra os passos que vai executar e pergunta se você deseja instalar (`y` para confirmar).

![Ao terminar, todos os passos aparecem co](/projects/clidocs/one-command-install-complete.png)

Ao terminar, todos os passos aparecem como concluídos e o instalador informa onde o `clidocs` foi instalado.

## O que o instalador faz

1. Encontra a última release no GitHub
2. Baixa o `clidocs.exe`
3. Verifica o checksum SHA-256
4. Instala em `%LOCALAPPDATA%\clidocs`
5. Adiciona essa pasta ao `PATH` do usuário
6. Cria o comando `clidocs` no PowerShell

Abra um **novo** terminal e digite `clidocs`. Executar o instalador de novo atualiza uma instalação existente.

## Outras opções

### Opção 2: executável do instalador

Baixe o `clidocs-installer.exe` na [página de releases](https://github.com/F4NT0/clidocs/releases) e execute, ou compile o instalador:

```powershell
go build -o clidocs-installer.exe ./cmd/clidocs-installer
.\clidocs-installer.exe
```

### Opção 3: pelo repositório clonado

```powershell
git clone https://github.com/F4NT0/clidocs.git
cd clidocs
go run . --install
```

:::note
`go run . --install` executa o mesmo instalador e instala a **última release publicada**, não a árvore de trabalho local.
:::

### Opção 4: de um clidocs já instalado

```powershell
clidocs --install      # instala ou atualiza para a última release
clidocs --install -y   # pula a confirmação
```

### Desinstalar

```powershell
clidocs --uninstall      # pede confirmação
clidocs --uninstall -y   # pula a confirmação
```

Remove o alias do PowerShell, as entradas do `PATH` e todo `clidocs.exe` encontrado no `PATH`. As pastas só são removidas quando estão vazias. **Seus snippets nunca são apagados.**

## Primeira execução

Abra qualquer janela do PowerShell e execute:

```powershell
clidocs
```

:::note[Pasta dos snippets]
Os snippets ficam em `%USERPROFILE%\clidocs_snippets\`. A pasta é criada automaticamente na primeira execução e cada subpasta vira uma categoria no painel Folders.
:::
