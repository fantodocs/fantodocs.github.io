## Requisitos

| Requisito | Para que serve |
|---|---|
| **Windows 10 / 11 (64 bits)** | Sistema suportado |
| **PowerShell 5.1+** | Já vem no Windows, usado nos diálogos de arquivo |
| **Neovim (`nvim`)** | Editar snippets (`Enter` / `e`) |
| **Git** | Sincronização com o GitHub (`g`) |
| **Windows Terminal (`wt`)** | Recomendado, abre o Neovim em uma nova aba |
| **VS Code (`code`)** | Opcional, abre arquivos com `v` |
| **Nerd Font** (JetBrainsMono) | Ícones das pastas |
| **Go 1.24+** | Somente para compilar do código-fonte |

Instale os pré-requisitos com o `winget`:

```powershell
winget install Neovim.Neovim
winget install Git.Git
winget install Microsoft.WindowsTerminal
```

:::tip[Nerd Font]
Baixe a [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads), instale os arquivos `.ttf` e defina a fonte nas configurações do perfil do Windows Terminal.
:::

## Instalação com um único comando

Escolha o seu sistema operacional:

<Tabs>
  <TabItem label="Windows">

Abra o **PowerShell** e cole o comando abaixo. Ele baixa o `clidocs.exe` e o instalador (`install.exe`) da última release para `%USERPROFILE%\clidocs` e abre o instalador como Administrador.

```powershell title="PowerShell"
$d = "$env:USERPROFILE\clidocs"
New-Item -ItemType Directory -Force $d | Out-Null
iwr https://github.com/F4NT0/clidocs/releases/latest/download/clidocs.exe -OutFile "$d\clidocs.exe"
iwr https://github.com/F4NT0/clidocs/releases/latest/download/install.exe -OutFile "$d\install.exe"
Start-Process "$d\install.exe" -WorkingDirectory $d -Verb RunAs
```

Depois, siga o assistente do instalador:

<Steps>
1. Escolha a pasta de instalação e clique em **Next**.
2. Se já existir um `.exe` no local (atualização), o instalador pergunta se deseja substituí-lo.
3. Aguarde a mensagem de sucesso. O `clidocs` é adicionado ao `PATH` automaticamente.
4. Abra um **novo** terminal e execute `clidocs`.
</Steps>

### Download manual

Baixe `clidocs.exe` e `install.exe` direto na [página de releases](https://github.com/F4NT0/clidocs/releases), coloque os dois na mesma pasta e execute `.\install.exe` como **Administrador**.

  </TabItem>
  <TabItem label="Linux">

:::caution[Linux ainda não é suportado]
O clidocs usa APIs do Windows (`syscall.NewLazyDLL`, PowerShell e diálogos nativos de arquivo). Por isso não existe binário nem instalador para Linux, e compilar com `GOOS=linux` falha. Hoje não há um comando de instalação nativo para Linux.
:::

A alternativa é usar o **WSL 2** e abrir o `clidocs.exe` instalado no Windows:

```bash title="WSL"
/mnt/c/Users/SEU_USUARIO/clidocs/clidocs.exe
```

  </TabItem>
  <TabItem label="macOS">

:::caution[macOS ainda não é suportado]
Pelos mesmos motivos do Linux, não existe binário nem instalador para macOS. Quando houver suporte nativo, o comando de instalação será publicado aqui.
:::

Acompanhe o andamento na [página de releases](https://github.com/F4NT0/clidocs/releases) do projeto.

  </TabItem>

## Compilando do código-fonte

Requer **Go 1.24+**.

```powershell
git clone https://github.com/F4NT0/clidocs.git
cd clidocs
go mod tidy
go build -o clidocs.exe .
.\clidocs.exe
```

## Primeira execução

Abra qualquer janela do PowerShell e execute:

```powershell
clidocs
```

:::note[Pasta dos snippets]
Os snippets ficam em `%USERPROFILE%\clidocs_snippets\`. A pasta é criada automaticamente na primeira execução e cada subpasta vira uma categoria no painel Folders.
:::
