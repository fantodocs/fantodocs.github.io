## Running the program

After [installing clidocs](/en-us/projects/clidocs/install/), open the terminal and run:

```powershell
# Opens the default snippets directory (~\clidocs_snippets)
clidocs

# Opens the current directory as the snippets root
clidocs .

# Opens a specific directory
clidocs C:\Users\You\my-snippets
clidocs .\docs\snippets
```

:::note[Snippets]
Snippets are stored in `%USERPROFILE%\clidocs_snippets\`. The folder is created on first run and each sub-folder becomes a category in the Folders panel.
:::

## Splash screen

When you run `clidocs` **without arguments**, an ASCII art welcome screen is shown. It is skipped when you pass a path (`clidocs .` or `clidocs <path>`).

## Interface

The interface has three panels controlled by the keyboard:

![clidocs interface](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/visualization.png)

| Panel | Description |
|---|---|
| **Folders** | Snippet categories. The selected folder is shown in blue with `>`. Folders with subfolders show a `›` indicator. Use `←` to go back. |
| **Snippets** | Files in the selected folder. The selected file is shown in green, with an extension badge in the language color. |
| **Preview** | Syntax-highlighted content. Shows the full file path in orange and is scrollable. |

## Folder management

### Create a folder

<Steps>
1. Focus the **Folders** panel.
2. Press `n`, type the name and confirm with `Enter` (or `Esc` to cancel).
</Steps>

![Create folder](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/create-new-folder.png)

### Rename a folder

<Steps>
1. Navigate to the folder in the **Folders** panel.
2. Press `R`. A modal appears with the current name.
3. Edit the name and confirm with `Enter`. Favorites pointing to the folder are updated automatically.
</Steps>

![Rename folder](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/rename-folder.png)

### Delete a folder

<Steps>
1. Navigate to the folder in the **Folders** panel.
2. Press `D`. A confirmation modal appears.
3. Press `Enter` or `y` to delete, `Esc` or `n` to cancel.
</Steps>

:::danger[Warning]
Deletion is permanent and recursive: all files and subfolders are removed from disk.
:::

![Delete folder](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/delete-folder.png)

## Subfolder navigation

Folders that contain subfolders display a `›` indicator next to their name.

![Subfolder indicator](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/subfolder-navigation.png)

### Browsing subfolders

<Steps>
1. Select a folder with `›` in the Folders panel. The Snippets panel already shows its direct files.
2. Press `Enter` to enter **parent-view mode**: the panel title changes to the folder name with `← back`, the first row is `~/` (the folder own files) and the rest are subfolders.
3. Press `Enter` on a subfolder. With no sub-subfolders it navigates straight into it. With children it enters parent-view again.
4. Press `←` to go back to the previous level.
</Steps>

![Subfolder snippets](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/subfolder-snippets.png)

### Create a subfolder

<Steps>
1. Select a folder in the Folders panel.
2. Press `N` and type the subfolder name.
3. Confirm with `Enter` or cancel with `Esc`.
</Steps>

![Subfolder creation](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/subfolder-creation.png)

## Folder search

<Steps>
1. Focus the **Folders** panel.
2. Press `/`. The title shows `/ query█`.
3. Type to filter. Use `↑`/`↓` to navigate the results.
4. `Enter` confirms and `Esc` cancels and restores the full list.
</Steps>

![Folder search](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/search-folders.png)

## Snippets management

### Create a file

<Steps>
1. Focus the **Snippets** panel with a folder selected.
2. Press `n`.
3. **Step 1:** enter the file name (without extension) and press `Enter` or `Tab`.
4. **Step 2:** enter the extension (e.g. `go`, `py`, `md`) and press `Enter` to create and open.
</Steps>

![Create file](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/create-new-file.png)

### Rename a snippet

<Steps>
1. Navigate to the file in the **Snippets** panel.
2. Press `r`. The modal shows the current name.
3. Edit it and confirm with `Enter`, or cancel with `Esc`.
</Steps>

![Rename file](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/rename-file.png)

### Delete a file

<Steps>
1. Navigate to the file in the **Snippets** panel.
2. Press `d`. The modal shows the file name.
3. `Enter` or `y` deletes, `Esc` or `n` cancels.
</Steps>

:::caution[Warning]
File deletion is permanent.
:::

![Delete file](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/delete-file.png)

### Move a file to another folder

<Steps>
1. Navigate to the file in the **Snippets** panel.
2. Press `m` (requires at least 2 folders).
3. Pick the destination folder with `↑`/`↓`.
4. Press `Enter` to move.
</Steps>

![Move file](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/move-file.png)

### Inline file search

<Steps>
1. Focus the **Snippets** panel.
2. Press `/`. The title becomes a search input.
3. Type to filter (e.g. `*.go`, `docker`, `main.go`).
4. Use `↑`/`↓` to navigate. The preview updates live.
5. `Enter` confirms and `Esc` cancels.
</Steps>

![Inline file search](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/search-filter-snippets.png)

## Preview panel

The Preview panel shows the syntax-highlighted content of the selected file with additional information and actions.

### File path indicator

When a file is loaded, its **full absolute path** is displayed in orange below the file title.

![File path indicator](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/file-path-indicator.png)

### Open actions

| Key | Action |
|---|---|
| `e` | Open the file in **Neovim** (new Windows Terminal window) |
| `v` | Open the file in **VS Code** (`code <path>`) |
| `o` | Open the file **containing folder** in Explorer |

### Word search

<Steps>
1. Press `/`. A search bar appears below the title.
2. Type the word or phrase.
3. Press `Enter`. Matching lines are highlighted: **orange `▶`** is the current hit and **green `•`** are the other matches.
4. Press `n` / `N` to cycle through hits.
5. `Esc` closes the search.
</Steps>

![Preview word search](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/search-word-visualization.png)

### Line numbers

Press `L` to toggle line numbers. When active, matched search lines show their number in orange (current) or green (other hits).

![Line numbers](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/Show_Line_Numbers.png)

### Markdown preview

Files with a `.md` or `.markdown` extension are rendered with **[glamour](https://github.com/charmbracelet/glamour)**, using the GitHub Dark style. A **`[MD]`** badge appears in the preview title.

| Markdown | Rendered as |
|---|---|
| `# Heading` | Bold colored heading |
| `**bold**` | **Bold** text |
| `*italic*` | *Italic* text |
| Inline code between backticks | Inline code block |
| Fenced block with language | Syntax-highlighted code |
| `- list item` | Bulleted list |
| `> blockquote` | Quoted block |
| `[link](url)` | Styled link |
| `---` | Horizontal rule |

:::note[LaTeX]
LaTeX formulas (`$x^2$`, `$$\int$$`) are not rendered because the terminal has no math engine. Write them as ASCII (`x²`) or use a code block.
:::

![Markdown preview](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/markdown-preview.png)

### Keyword colorization

Status keywords written in uppercase anywhere in a markdown file are automatically colored in the Preview panel. No special syntax required.

| Keyword | Color | Notes |
|---|---|---|
| `TODO` | Soft blue | Task not started |
| `DOING` / `WORKING` | Yellow | Task in progress |
| `DONE` / `FINISH` | Soft green | Task completed, with an icon before the word |
| `FAIL` / `NOT` | Red | Task failed, with an icon before the word |

:::tip[Nerd Font]
The icons require a **Nerd Font** in your terminal (e.g. JetBrainsMono Nerd Font).
:::

### Icon shortcuts

You can embed Nerd Font icons in any markdown file using shortcodes. They are replaced with colored icons at render time.

| Shortcode | Icon | Color |
|---|---|---|
| `:check:` | `nf-fa-circle_check` | Green |
| `:x:` | `nf-fa-times_circle` | Red |
| `:work:` | `nf-cod-warning` | Yellow |

Example:

```markdown
- :check: Deploy to production
- :x: Rollback failed, investigate logs
- :work: Pipeline running, waiting for results
```

### Copy to clipboard

Press `c` in the Preview panel to copy the entire file content to the system clipboard. A green status message confirms the action.

![Copy to clipboard](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/copy-to-clipboard.png)

## Folder favorites

Favorites let you bookmark frequently used folders and jump to them instantly.

### Marking a favorite

<Steps>
1. Select a folder in the **Folders** panel.
2. Press `f`. The folder gets a `★` indicator and a green message confirms.
3. Press `f` again to unfavorite.
</Steps>

:::note[Favorites]
Favorites are saved to `.clidocs_favorites.json` inside the snippets directory and persist across sessions.
:::

![Folder favorites](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/folder-favorites.png)

### Navigating favorites

<Steps>
1. Press `F` (uppercase) in the Folders panel to open the **Favorites modal**.
2. Use `↑`/`↓` and `Enter` to jump to that folder.
3. Press `f` inside the modal to unfavorite the selected entry.
4. `Esc` or `F` closes the modal.
</Steps>

![Favorites modal](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/favorites-modal.png)

### Returning to the home directory

If you changed the snippets directory, the Folders panel title shows **`H:home`**. Press `H` to return to the original directory.

## Snippets directory

Press `o` (on the Folders or Snippets panel) to open the directory info modal.

| Action | Description |
|---|---|
| `Enter` | Opens the snippets folder in Explorer |
| `s` | Opens an Explorer-style folder picker to choose a new directory |
| `Esc` | Closes the modal |

:::note[Info]
Changing the directory takes effect immediately. The original default directory (`%USERPROFILE%\clidocs_snippets`) is never deleted.
:::

![Snippets directory](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/snippet-directory.png)

## Neovim integration

When you press `Enter` on a file in the Snippets panel (or `e` in the Preview panel), clidocs opens **Neovim in a new Windows Terminal window**.

![Open in Neovim](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/open-in-neovim.png)

:::tip[Fallback]
If Windows Terminal (`wt`) is not available, Neovim takes over the current terminal.

## File import

Copy any file from your computer into the currently selected folder:

<Steps>
1. Focus the **Snippets** panel.
2. Press `c`.
3. A native Windows **Open File** dialog appears.
4. Select one or more files and click Open.
</Steps>

:::tip[Tip]
Multi-selection is supported: hold `Ctrl` or `Shift` in the dialog.
:::

![Import file](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/import-file.png)

## GitHub sync

Back up and share your snippets by syncing to a GitHub repository.

![GitHub sync](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/sync-git.png)

### First use

Press `g`. A setup modal appears:

| Field | Example |
|---|---|
| **Repository URL** | `https://github.com/user/snippets.git` |
| **Username** | `your-github-username` |
| **Email** | `you@example.com` |

Navigate fields with `Enter` or `Tab` / `Shift+Tab`. The config is saved to `.clidocs_git.json`.

![Sync configuration](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/sync-config.png)

### How sync works

<Steps>
1. `git init` (first time only).
2. Pulls remote changes first to avoid conflicts.
3. `git add -A`, `git commit` and `git push -u origin main`.
4. Shows a success or error modal.
</Steps>

### Change configuration

Press `G` at any time to update the repository URL, username or email.

:::caution[GitHub]
The repository must exist on GitHub before syncing. For private repos, make sure credentials are cached via [Git Credential Manager](https://github.com/git-ecosystem/git-credential-manager) or use SSH.
:::

![GitHub sync](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/sync-complete.png)

## Console (easter egg)

Press `:` from **any panel** to open the `Cmdline` console, a command-line interface inside clidocs.

![Console](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/cmdline-screen.png)

### Available commands

| Command | Description |
|---|---|
| `time` | **Work hours calculator**: enter your start time (HH:MM) and get coffee break, lunch, normal exit and maximum exit times |
| `whoami` | Shows your custom user info (edit the `whoamiText` constant in `console.go`) |
| `nvim` | Opens the **Neovim quick reference**, a two-column cheat-sheet |
| `help` | Displays all keyboard shortcuts and console commands |
| `clear` | Clears the console output |
| `exit` / `quit` | Closes the console |

### Neovim quick reference (`nvim`)

Type `nvim` in the console and press `Enter` to open a reference modal covering:

- **Navigation:** `hjkl`, `gg`/`G`, `Ctrl+d`/`u`, word and line jumps
- **Editing:** insert modes (`i`, `a`, `o`), undo/redo, delete, yank, paste
- **Save and quit:** `:w`, `:q`, `:wq`, `:q!`
- **Search:** `/word` and `n`/`N` to cycle matches
- **Comment multiple lines:** `Ctrl+V`, block select, `:` and `'<,'>s/^/#`
- **Uncomment multiple lines:** `Ctrl+V`, block select, `:` and `'<,'>s/^#//`
- **Visual mode:** `v` (char), `V` (line), `Ctrl+V` (block)

![Neovim Quick Reference](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/cmdline-nvim-guide.png)

### Work hours calculator (`time`)

Based on a standard workday of **8h48** with 1h lunch, given your entry time:

| Output | Description |
|---|---|
| **Coffee break** | Suggested first break (+1h) |
| **Lunch start** | +4h after entry |
| **Lunch end** | +1h after lunch start |
| **Normal exit** | Entry + 8h48 work + 1h lunch |
| **Maximum exit** | Entry + 10h work + 1h lunch |

![Time calculator](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/cmdline-work-hours.png)

### Customizing `whoami`

Edit `console.go` and update the `whoamiText` constant with your info:

```go
const whoamiText = `
  Your Name
  Your Role
  GitHub: github.com/yourhandle
  ...
`
```

![whoami](https://raw.githubusercontent.com/F4NT0/clidocs/main/images/cmdline-whoami.png)

## Project structure

The project is in transition to Clean Architecture. Because Bubble Tea requires Update/View methods in the same package as the Model, core files stay in the root while auxiliary files were reorganized:

<FileTree>
- clidocs/

  - core application files (*.go)
  - console_modals.go
  - file_modals.go
  - folder_modals.go
  - git_modals.go
  - other_modals.go
  - README.md
</FileTree>
