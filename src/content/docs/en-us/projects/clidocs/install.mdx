## Requirements

| Requirement | Purpose |
|---|---|
| **Windows 10 / 11 (64-bit)** | Supported OS |
| **PowerShell 5.1+** | Built into Windows, used for file dialogs |
| **Neovim (`nvim`)** | Editing snippets (`Enter` / `e`) |
| **Git** | GitHub sync (`g`) |
| **Windows Terminal (`wt`)** | Recommended, opens Neovim in a new tab |
| **VS Code (`code`)** | Optional, opens files with `v` |
| **Nerd Font** (JetBrainsMono) | Folder icons |
| **Go 1.24+** | Only to build from source |

Install the prerequisites with `winget`:

```powershell
winget install Neovim.Neovim
winget install Git.Git
winget install Microsoft.WindowsTerminal
```

:::tip[Nerd Font]
Download [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads), install the `.ttf` files and set the font in the Windows Terminal profile settings.
:::

## One-command installation

Choose your operating system:

<Tabs>
  <TabItem label="Windows">

Open **PowerShell** and paste the command below. It downloads `clidocs.exe` and the installer (`install.exe`) from the latest release into `%USERPROFILE%\clidocs` and opens the installer as Administrator.

```powershell title="PowerShell"
$d = "$env:USERPROFILE\clidocs"
New-Item -ItemType Directory -Force $d | Out-Null
iwr https://github.com/F4NT0/clidocs/releases/latest/download/clidocs.exe -OutFile "$d\clidocs.exe"
iwr https://github.com/F4NT0/clidocs/releases/latest/download/install.exe -OutFile "$d\install.exe"
Start-Process "$d\install.exe" -WorkingDirectory $d -Verb RunAs
```

Then follow the installer wizard:

<Steps>
1. Select the installation path and click **Next**.
2. If there is already an `.exe` in the location (update), the installer asks whether to replace it.
3. Wait for the success message. `clidocs` is added to the `PATH` automatically.
4. Open a **new** terminal and run `clidocs`.
</Steps>

### Manual download

Download `clidocs.exe` and `install.exe` from the [releases page](https://github.com/F4NT0/clidocs/releases), put both in the same folder and run `.\install.exe` as **Administrator**.

  </TabItem>
  <TabItem label="Linux">

:::caution[Linux is not supported yet]
clidocs uses Windows APIs (`syscall.NewLazyDLL`, PowerShell and native file dialogs). Because of that there is no binary or installer for Linux, and building with `GOOS=linux` fails. Today there is no native install command for Linux.
:::

The workaround is to use **WSL 2** and run the `clidocs.exe` installed on Windows:

```bash title="WSL"
/mnt/c/Users/YOUR_USER/clidocs/clidocs.exe
```

  </TabItem>
  <TabItem label="macOS">

:::caution[macOS is not supported yet]
For the same reasons as Linux, there is no binary or installer for macOS. When native support lands, the install command will be published here.
:::

Follow progress on the project [releases page](https://github.com/F4NT0/clidocs/releases).

  </TabItem>

## Building from source

Requires **Go 1.24+**.

```powershell
git clone https://github.com/F4NT0/clidocs.git
cd clidocs
go mod tidy
go build -o clidocs.exe .
.\clidocs.exe
```

## First run

Open any PowerShell window and run:

```powershell
clidocs
```

:::note[Snippets folder]
Snippets are stored in `%USERPROFILE%\clidocs_snippets\`. The folder is created automatically on first run and each sub-folder becomes a category in the Folders panel.
:::
